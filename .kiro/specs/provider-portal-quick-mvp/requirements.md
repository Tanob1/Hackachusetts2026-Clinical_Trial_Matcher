# Provider Portal Quick MVP - Requirements

## Feature: Hospital Provider Portal (Minimal Version)

### User Flow
1. Doctor logs in → 2. Searches patient → 3. Views matches → 4. Generates QR referral

### Tasks
1. Database: Add providers & referrals tables
2. Auth: Provider login/logout routes
3. Search: Patient search by name
4. Profile: View patient + matched trials
5. QR: Generate referral QR codes
6. Templates: 4 HTML pages
7. Testing: End-to-end workflow

### Time: ~1.5 hours
